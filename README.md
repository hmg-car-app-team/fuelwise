# 알뜰주유 FuelWise

가장 싼 주유소도 돌아가는 기름값을 더하면 더 비쌀 수 있습니다. 이 앱은 우회 비용까지 합친 실질 비용으로 주유소를 비교해 추천하고, 잔량이 낮아지면 음성으로 알려 줍니다. 충전소와 배터리 잔량도 다룹니다. (`com.hmgcarapp.fuelwise`)

## 주요 기능
- **실질 비용 순위**: 단가 x 주입량 + 우회 연료·전력비로 후보를 비교합니다. 절약액은 우회가 가장 적은 후보를 기준으로 하며, 연비·전비는 설정한 값으로 계산합니다.
- **잔량 알림**: 연료 또는 배터리 잔량이 설정 기준 이하가 되면 내비 경로를 확인한 뒤 음성으로 안내합니다. "응", "추가해줘" 같은 짧은 답으로 경유지를 추가하거나 안내를 시작하고, 결과를 음성으로 알려 줍니다.
- **전기차 모드**: 충전 출력·대기·우회를 반영해 충전소를 비교합니다. 충전 요금과 대기시간은 가정값이라 요금 비교와 절약 계산에는 쓰지 않습니다.
- **할인 카드와 월 리포트**: 카드 할인을 반영하고, '주유/충전 완료 기록'을 바탕으로 월 추정 절약을 보여 줍니다.

## 실행 방법
1. 아래 APK를 에뮬레이터에 설치합니다.
   ```
   adb install -r apk/hmg-car-app-team_FuelWise_release.apk
   ```
2. 앱 아이콘으로 실행하고, 첫 실행의 권한은 정차 상태에서 허용합니다.

## 테스트 환경
- Pleos Connect v2.1.0 에뮬레이터 (AVD 이름 pleos21), Android 14 (API 34)
- 화면: 2560x1440, 가로(Landscape)

## APK 위치
`apk/hmg-car-app-team_FuelWise_release.apk`

## 데이터 출처
- **충전소 정보**: 한국환경공단 『전기자동차 충전소 정보』(공공데이터포털 data.go.kr), 공공누리 제1유형(출처표시), 가공·편집됨. 기준일 2026-11-11.
- **유가·주유소 목록**은 가공 샘플이며, 화면의 절약액은 실제 금액이 아닙니다.
- 충전 요금은 가정 단가이므로 요금 비교와 절약 계산에서 제외합니다.

## 개인정보
설정과 주유·충전 완료 기록은 이 기기에만 저장하며 서버로 전송하지 않습니다. 현재 위치 좌표는 저장하지 않고, 기록은 리포트에서 삭제할 수 있습니다.

## 소스 빌드·테스트
`app/` 폴더만으로 단독 빌드됩니다(JDK 17, Android SDK 필요, Pleos SDK 는 공개 Maven 에서 받으므로 인터넷 필요).

```bash
cd app
./gradlew :fuel-wise:assembleDebug :fuel-wise:assembleRelease
./gradlew :core:test :fuel-wise:testDebugUnitTest
```

서드파티 고지는 `app/NOTICE`, 폰트 라이선스는 `app/licenses/` 에 있습니다.
