## 문서와 불일치 / 관찰
- 문서(README·fuel-wise.md)는 '손상 시 설정 > 저장된 기록 안내는 상시 표시'라고 하나, `.corrupt` 가 곧 삭제되어 안내를 볼 수 없었음(D2).
- 삭제 확인 팝업 본문은 '기록 N건이 삭제돼요. 되돌릴 수 없어요.' 만 보임(보존본·임시 파일 삭제 안내는 이 경우 미표시; fixE2_06 증거와 상황이 다를 수 있음 — 보존본이 없을 때일 수 있음, 미확정).
- 설정 화면(debug)에 SDK 예외 문자열(IllegalArgumentException …)이 그대로 노출됨(debug 전용 패널이라 release 에는 없음).
- 권한 대화상자 3번째 라벨이 '알 수 없는 작업'(시스템 번역; 앱 선언 권한 라벨 미정의 가능성).
